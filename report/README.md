# Final report

The submission source is `latex/main.tex`. The current compiled paper is available as
`REPORT.pdf` (the easy-to-find submission copy) and `latex/main.pdf` (the build output);
the two files must remain byte-identical. `latex/EXPERT_REVIEW.md` contains a skeptical
evidence audit. `REPORT.md` is the earlier narrative draft retained for provenance.

**Status: complete.** The final coding rerun, LiveCodeBench, verifier check, and
five-dimension persona judge are all incorporated. No evaluation remains pending.

## Rebuild

From the repo root:

```bash
uv pip install matplotlib numpy scipy   # if not already in the env
python report/scripts/collect.py        # gathers generations and surface metrics into report/data/
python report/scripts/stats.py          # derived summary statistics -> data/stats.json
python report/scripts/fig_tradeoff.py   # Figure 1
python report/scripts/fig_markers.py    # Figure 2
python RLVR/figures/plot_rlvr.py        # RLVR data-selection and checkpoint figures
python report/scripts/fig_canon_rater.py  # Figure 5
python report/scripts/fig_collapse.py     # Figure 6
cd report/latex
tectonic main.tex                       # paper source -> main.pdf
cp main.pdf ../REPORT.pdf               # update the submission copy
```

See `latex/EXPERT_REVIEW.md` for the skeptical editorial review.

## Data

| file | what it is |
| --- | --- |
| `data/all_generations.json` | held-out persona generations for every stage, plus the reference replies |
| `data/first_rlaif_attempt/` | the abandoned first RLAIF run, recovered from commit `070e788`: trainer log, evals, generations |
| `data/rocky_canon.md` | the canon speech profile of book Rocky, written by a research agent with cited sources |
| `data/opus_rater_key.json`, `data/ratings_{1,2}.json` | the blind canon-grounded rating: the answer key, and the raw ratings from two rater agents (160 replies) |
| `data/live_key.json`, `data/live_ratings.json` | the blind human rating (16 replies) and its answer key |
| `data/surface_metrics.json`, `data/stats.json` | derived numbers; regenerate with the scripts above |
| `../RLVR/data/rlvr_pool_1700.jsonl` | 1,700-problem source pool for the final RLVR run (Git LFS) |
| `../RLVR/data/rlvr_dataset.jsonl` | exact 700-problem, difficulty-ordered RLVR training set |

The RLVR selection figures are generated by `RLVR/figures/plot_rlvr.py`.
